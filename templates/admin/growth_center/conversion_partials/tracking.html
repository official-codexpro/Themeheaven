  • Server-side form events are recorded only after a successful save and never include form payloads.
  • data-track-event — recorded event name.
  • data-track-name — human-readable source label; never a payload.
  • data-track-type — optional event type such as download, email_click, or external_link_click.
  • data-track-goal — optional active goal key.
  • data-track-path — optional page path override.
